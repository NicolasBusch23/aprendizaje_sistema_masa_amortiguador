This folder contains the code for reproducing the example in

"Probabilistic learning of nonlinear dynamical systems using 
sequential Monte Carlo" (2017) by Thomas B. Schon, Fredrik
Lindsten, Andreas Svensson, Lawrence Murray.

The code is written in LibBi. Instruction on how to install
LibBi are found on http://libbi.org/getting-started.html
