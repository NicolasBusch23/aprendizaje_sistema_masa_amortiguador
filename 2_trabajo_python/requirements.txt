# Dependencias para ejecutar la inferencia y las figuras del ejemplo Damper
# (reimplementacion en Python del modelo del articulo de Schon et al., 2018).
#
# Instalacion (desde la carpeta Damper):
#   py -m venv .venv
#   .\.venv\Scripts\Activate.ps1      # PowerShell  (o .venv\Scripts\activate.bat en cmd)
#   pip install -r requirements.txt
#
# Uso:
#   python pmh_damper.py --iter 10000 --part 256
#   python ver_resultados.py
#
# Los algoritmos (filtro de particulas bootstrap, MH pseudo-marginal y PMH) estan
# programados desde cero; ninguna de estas librerias implementa inferencia bayesiana.

# --- Usadas en pmh_damper.py (inferencia) ---------------------------------------

# --- Usadas en ver_resultados.py (figuras y resumenes) ---------------------------

# Genera las figuras 01 a 04 (datos, posteriores, trazas y estados) en PNG y PDF.
